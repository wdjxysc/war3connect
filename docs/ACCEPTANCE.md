# 第一版验收

## 自动验证

执行 `./scripts/build.ps1 -Test`，失败时进程返回非零退出码。测试数据和服务端日志保存在 `artifacts/tests/`。测试启动的服务器在退出时结束，不留后台进程。

覆盖：协议黄金字节、公告解析与截断检查、改写端口时保留其他字段、完整版本检查、密码/容量拒绝、无地图入房、无地图公告、原生地图信息保留、同房间换图、6 MiB 连续转发及限速后连接保持、匿名和越权拒绝、令牌撤销、账号持久化、房间聊天、UDP 发现与重发、两名模拟玩家同时经过 TCP→WS→TCP 链路、不同长度数据的分片重组、公告过期后已有连接保持、关闭 TCP/房间后的资源回收、未配对连接超时、心跳超时。

## 原生地图流程验证（0.3.0，2026-09-14）

- Windows / Ubuntu 24.04 x64 各 61 项自动检查通过，Release 构建零警告、零错误。

- 上述使用模拟游戏和字节流，不等同于 War3 原生地图下载握手、进度、落盘及完整对局验收。
- 客户端与服务端需要同步升级。此轮验证使用独立测试服务，没有替换公网服务。
