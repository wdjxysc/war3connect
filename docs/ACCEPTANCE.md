# 第一版验收

## 自动验证

执行 `./scripts/build.ps1 -Test`，失败时进程返回非零退出码。测试数据和服务端日志保存在 `artifacts/tests/`。测试启动的服务器在退出时结束，不留后台进程。

覆盖：协议黄金字节、公告解析与截断检查、改写端口时保留其他字段、完整版本检查、地图/密码/容量拒绝、匿名和越权拒绝、令牌撤销、账号持久化、房间聊天、UDP 发现与重发、两名模拟玩家同时经过 TCP→WS→TCP 链路、不同长度数据的分片重组、公告过期后已有连接保持、关闭 TCP/房间后的资源回收、未配对连接超时、心跳超时。
